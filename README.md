# Practical Evaluation of AI-generated Images Using Automated Quality Metrics

## Overview

This repository contains the code, dataset structure, result files, and figures used for the individual project:

**Practical Evaluation of AI-generated Images Using Automated Quality Metrics**

The project compares image outputs from **GPT-5.2** and **JiMeng AI** using three automated evaluation metrics:

- **CLIP Score** for semantic alignment between images and prompts
- **LPIPS** for perceptual variation within controlled prompt variants
- **FID** for dataset-level distributional difference between model outputs

The aim of the project is not only to compare the two image generation systems, but also to examine how different automated metrics behave in practice and what aspects of image quality they capture.

## Dataset Design

The dataset was created using:

- **15 base prompts**
- **4 controlled prompt variants** for each prompt
- **2 image generation systems**: GPT-5.2 and JiMeng AI

This produced a total of:

**15 × 4 × 2 = 120 images**

The prompt variants were designed to preserve the same semantic content while changing viewpoint and framing:

- top-down overhead view, centered composition
- eye-level front view, medium shot
- low-angle view from below, wide shot
- extreme close-up, shallow depth of field

This controlled design was used because repeated prompts in the web-based GPT-5.2 interface produced identical or near-identical outputs, which made straightforward repeated sampling unsuitable.

---

## Evaluation Metrics

### 1. CLIP Score
Used to measure semantic alignment between each generated image and its corresponding prompt.

### 2. LPIPS
Used to measure perceptual variation within each prompt group by comparing the four controlled variants generated by the same model.

### 3. FID
Used to measure distributional difference between the full GPT-5.2 image set and the full JiMeng AI image set.

## Running the Evaluation

To run the evaluation pipeline:

```bash
python evaluate_images.py
```

The script expects the dataset folders to be organised as shown in the repository structure above.

---

## Outputs

Running the script produces:

- CLIP scores for each image
- LPIPS scores for all pairwise comparisons within each prompt/model group
- CLIP summary statistics by model and by prompt
- LPIPS summary statistics by model and by prompt
- one overall FID score comparing GPT-5.2 and JiMeng AI outputs

These outputs are stored in the `results/` directory.
